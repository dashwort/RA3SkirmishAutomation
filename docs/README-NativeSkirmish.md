# Direct launch

Direct launch starts a supported Red Alert 3 installation straight into the selected skirmish preset. It is available for the base game and the supported Epic War 5.4 configuration.

## Before you start

1. In Settings, confirm the game folder and active profile.
2. From the **Recovery** tab, install support for the supported game version.
3. Make sure Windows is signed in, connected, and unlocked.
4. Select a preset and start the game.

The profile selected in the launcher must match the profile currently selected in Red Alert 3. Use the standard route for other mods.

## During and after a game

Keep the launcher open until Red Alert 3 closes and cleanup finishes. The launcher protects the game settings it needs, then restores them when the session ends. Avoid editing the profile or map files while a direct-launch session is running.

If an operation is interrupted, use **Recovery > Recover** and follow the status message. To remove native support and return to the original game file, use **Recovery > Restore original**. Do not replace game files manually.
