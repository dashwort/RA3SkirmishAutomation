# Launch routes

Choose a game or mod in the launcher and select **Launch game**. The launcher chooses the route for you:

- Red Alert 3 and the supported Epic War 5.4 configuration use direct launch with the supported patched game binary.
- Other mods use Red Alert 3's standard menu launch.

There is no separate launch-mode setting. Install support for the patched game binary from the **Recovery** tab before using direct launch. Select **Apply settings** after changing launcher settings.

For screen-by-screen guidance, see the [launcher guide](README-WinUI-Launcher.md).
